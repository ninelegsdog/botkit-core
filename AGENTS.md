# AGENTS.md

## Роли

- **Пользователь** = владелец продукта. Решает, что делаем и что Releasing.
- **Агент** = инженер. Проактивен: доводит задачу до наблюдаемого результата.

## Что это

Общая библиотека для девяти продакшен-ботов BotKit. Из неё боты берут платежи, метрики,
ошибки, логирование, трассировку, Sentry и сборку webhook-приложения.

## Критическое ограничение

**Это публичный API для девяти потребителей.** Каждый бот пинит конкретный тег
(`botkit-core @ git+https://...@v0.8.2`). Следовательно:

- ломающее изменение требует **нового тега** и обновления пина во всех девяти репозиториях;
- нельзя менять сигнатуры `PaymentProvider` и функции из `metrics.py` без мажорного бампа;
- всё, что добавляется, должно быть **необязательным**: у модуля нет права требовать
  переменную окружения или открывать соединение в момент импорта.

## Обязательные правила

- Строка ≤ 120 символов, PEP8, type hints
- Conventional Commits
- Тесты пишутся до коммита; гейт покрытия 70 % не снижается молча
- `ruff check .` и `mypy botkit_core/` должны проходить
- Секреты — только у вызывающего бота. Библиотека читает только `BUILD_SHA` и
  `OTEL_EXPORTER_OTLP_ENDPOINT`, оба опциональны
- Импорт без побочных эффектов: ничего не открывается при `import`

## Контракты, которые нельзя вывести из кода

- **`payments.py` обязан поддерживать три провайдера.** ЮKassa — для офлайн-услуг и B2B,
  Telegram Stars (XTR) — для цифровых товаров и услуг (требование Telegram), Mock — для тестов.
  Добавление провайдера не должно ломать остальные.
- **`errors.py` получает счётчик через внедрение** (`set_errors_counter`), а не импортирует
  его напрямую: иначе возникает циклическая зависимость `errors` ↔ `metrics`.
- **Расхождение между ботами закрывается внедрением, а не копированием.** Если поверхность
  расходится в трёх поколениях `src/core` — выноси только байт-идентичное, остальное оставляй
  в боте.
- **Откат должен быть возможен без изменения кода бота.** Каждый бот сохраняет локальный shim,
  который реэкспортирует отсюда, — поэтому не удаляй символы, пока боты не мигрировали.

## Гейты перед коммитом

```bash
ruff check .
mypy botkit_core/
pytest -q                 # гейт покрытия 70 %, фактически 81 %
```

Интеграционные тесты — только с `--run-integration`, они требуют контейнеры.

## Где канон

Код ведётся на машине `predator`; копии каноном не являются. Публикация — только с машины,
где настроена авторизация GitHub. Проверка публикации — неаутентифицированный GitHub API.
